# Source catalogue provenance

`source-catalogue.csv` is copied from [International Reputation Source Map v1.0.0](https://github.com/mhdteto/international-reputation-source-map/blob/v1.0.0/data/sources.csv). It contains 16 real public entry points plus original curation notes, checked on 1 November 2026. It is separate from the fictional Alex Rowan / Cedar Notes evidence inputs.

Keep verification levels, scope, access limitations, primary-reference URLs and dates intact. A page read, a confirmed official link and an indexed description are different observations. A blocked service is not described as tested. No entity record, listed credential, company quality or general reputation is verified by inclusion in this catalogue.

Original curation notes are by Mohammed Teto, CC BY 4.0 under the source repository's notices. Rights in external linked records remain with their publishers. Refreshing this snapshot requires a dated source review; the demo never fetches or silently updates it.
