# Contributing

Open an issue describing the problem and the affected layer, template or definition. For factual changes, include a primary source and access date. For methodological changes, state the assumptions and how comparability would be affected. Keep observations, hypotheses and recommendations distinct.

Use English for primary documentation. Language-specific additions should explain adaptations rather than assume that translation preserves measurement conditions. Do not submit confidential client data, personal records without authorization, fabricated observations or promotional link lists.

Run `python3 tools/validate.py` before submitting a pull request. By contributing, you agree that your contribution uses the relevant repository license. Search/AI provider behavior must be described with dates and limitations.
